FONTLOG for Tangping (躺平体)
=============================

This file provides detailed information on the Tangping font software.
This information should be distributed along with the Tangping fonts and
any derivative works.


Basic Font Information
----------------------

Tangping is a display typeface whose Latin letters are drawn as bold Hei
(sans-serif) Chinese characters lying on their side. The idea: turn 曼 a
quarter-turn, cut it straight across, and its three parts read M A N.

Two styles share one design:
- Tangping Regular: capitals M N V W X Y Z sit short, as in the original MAN.
- Tangping Even: every capital is tall.
In both, lowercase stands on the short height (527), with ascenders up to the
capital height (689) and descenders to -190, in the same stroke weights.

Character set: Basic Latin, Latin-1 letters and symbols, Œ œ Š š Ž ž Ÿ ı,
general punctuation, € ™, arrows and the corner brackets 「 」. Since 3.200: the
full Google Fonts Latin Core set with combining accents (380 glyphs).

The fonts are generated from code (sources/build.py). Every glyph is
built from a small set of stroke primitives: stems, bars with concave
flared ends, 撇 (falling, tapering) and 捺 (rising, overshooting) strokes,
and Hei turns (the rounded corners of 九, 己, 乚) wherever a letter is round.


Information for Contributors
----------------------------

Edit sources/build.py and run `make` to rebuild the fonts and web fonts.
Run `make check` to validate with OTS and Font Bakery before a release.
The research/ folder contains the tools used to find a real source
character for each letter; they need Noto Sans CJK (SIL OFL), which is
not part of this font and is not redistributed here.


ChangeLog
---------

22 October 2026 (The Tangping Project Authors) Tangping v4.100
- Fixes from an independent review: filled counters in accented letters (now
  checked at build time); short M N V W X Y Z only inside all-caps in Regular
  (calt); new quotes, &, ß ẞ § £ ð Þ ¿ ~; narrower lowercase accents so Czech and
  Slovak words stay whole; kerning; tighter Hei turns.

22 October 2026 (The Tangping Project Authors) Tangping v4.000
- Redesign: Hei turns replace chamfers, notches and hooks; a real lowercase with
  ascenders and descenders in the capitals' stroke weights; tapering 撇 diagonals;
  new sources for E (端), K (否) and U (烹).

22 October 2026 (The Tangping Project Authors) Tangping v3.200
- Fixes from a design audit: distinct D/O, B/8, S/5, 6/8/9, I/1, 0/O; lowercase
  narrower and lighter; i and j dotted; shape-based spacing; automatic class
  kerning; Latin Core coverage with mark positioning; tabular figures; hinting.

21 October 2026 (The Tangping Project Authors) Tangping v3.100
- Letters redrawn to follow their source characters; distribution metadata;
  kerning for wide T; source map.

21 October 2026 (The Tangping Project Authors) Tangping v3.000
- Lowercase, accented Latin, punctuation and symbols, kerning, web fonts.

21 October 2026 (The Tangping Project Authors) Tangping v2.000
- M, A, N traced from the 曼 → MAN reference; stroke system derived from it.
